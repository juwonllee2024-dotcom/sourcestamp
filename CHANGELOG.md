# Changelog

All notable changes to SourceStamp are recorded here.

## [0.1.0] - 2026-08-29

### Added

- local Chrome MV3 popup for selected web text;
- visible quote, title, URL, capture time, and SHA-256 receipt fingerprint;
- explicit Markdown, HTML, and `.md` export actions;
- least-privilege manifest with no storage or network permissions;
- unit tests, package smoke test, CI, security policy, and contributor guide.
